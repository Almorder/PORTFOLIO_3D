# DESIGN SYSTEM V16 — Fabrica structure × Nolan Arc DA

## Typographies

- Yrsa : wordmark, grands titres, voix éditoriale.
- Syne : navigation, labels, chiffres, UI.
- DM Sans : paragraphes, formulaires, lecture fonctionnelle.

## Couleurs

- Ink : `#080706`
- Ivory : `#F0EBE2`
- Ember : `#CC460C`
- Ember soft : `#E97736`

## Formes

- grands rayons ;
- surfaces vitrées ponctuelles ;
- pas de diagonales agressives ;
- profondeur par transparence, blur et échelle légère ;
- grain global discret.

## Motion

La motion doit expliquer une relation ou attirer vers une décision :

- preloader Home uniquement ;
- barre de progression fine en haut ;
- reveal avec déplacement / blur / scale léger ;
- Journey piloté par le scroll ;
- Video Slide Show à inertie ;
- stats scroll-triggered ;
- hover logos monochrome → orange ;
- transitions de panneaux Pricing / Expertise ;
- reduced motion = contenu immédiatement lisible.

## Mobile

Le mobile est une composition dédiée :

- Nolan.Arc en haut à gauche ; Menu en haut à droite ;
- dock glass fixe en bas ;
- TOC latéral masqué ;
- sections en une colonne lorsque nécessaire ;
- pricing et expertise via tabs horizontaux ;
- cartes logos en grille 2 colonnes ;
- FAQ et formulaires conçus pour le pouce ;
- aucune animation ne bloque l'interaction.
