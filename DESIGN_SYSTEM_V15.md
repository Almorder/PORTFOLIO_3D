# Design System V15

## Règle
**Fabrica structure. Nolan Arc identity.**

## Typographies
- Yrsa : wordmark, grands titres, voix éditoriale.
- Syne : navigation, labels, catégories, UI.
- DM Sans : lecture, formulaires, informations fonctionnelles.

## Couleurs
- Ink `#080706`
- Paper `#F0EBE2`
- Ember `#CC460C`
- Ember soft `#E97736`

## Formes
- grands rayons sur médias et scènes ;
- surfaces glass uniquement pour navigation, formulaires et contrôles ;
- pas de diagonales structurelles agressives ;
- grain global léger.

## Motion
- reveal : translation + blur + légère échelle ;
- médias : scale très mesuré ;
- scroll : utilisé pour méthode / navigation / progression ;
- reduced motion : contenu immédiatement visible et animations coupées.
