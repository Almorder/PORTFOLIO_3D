# COMPONENT IMPLEMENTATION V11

Les composants demandés restent des implémentations indépendantes HTML/CSS/JS inspirées des comportements publics des composants Framer. Aucun code source propriétaire premium n'est présenté comme ayant été copié.

## État des 12 composants

1. **Page View Counter** — code Supabase REST + SQL fourni ; affichage seulement après configuration réelle.
2. **Hold Confirm** — maintien, progression, annulation, tactile/clavier.
3. **Glassy Button** — verre, profondeur, shine, hover et pressed.
4. **Focus Testimonials** — focus desktop, mode mobile lisible, expander.
5. **Glass Showcase Pro** — reconstruction Three.js/WebGL + fallback image + particules.
6. **Logo Preloader** — entrée logo + fail-safe JS/CSS.
7. **Ambient Video Player** — halo dynamique autour du lecteur ; pas de faux frame sampling YouTube.
8. **Stacked Flow** — pile, profondeur, molette, swipe, clavier, contrôles.
9. **Video Slide Show** — éventail portrait, dots, mute, swipe, autoplay, timecodes.
10. **Animated Stats Pro** — count-up, easeOutExpo, blur/slide/fade/scale. V11 garantit un contenu lisible si l'animation ne se déclenche pas.
11. **Line Menu TOC** — vertical à gauche ; V11 le garde replié au repos, l'ouvre au hover/focus et le referme avec délai.
12. **Gradient Motion Background** — reconstruction indépendante avec Radial / Conic / Mesh / Linear / Diamond.

## Principe V11

Un composant n'est conservé visuellement que s'il aide à :
- comprendre ;
- prouver ;
- naviguer ;
- retenir l'attention ;
- ou déclencher l'action suivante.

Le portfolio ne doit pas devenir une démonstration de composants Framer.
