# V14 — Direction locked

V14 does not replace the V13/Fabrica architecture. It restores the Nolan Arc visual identity on top of it.

## Main decisions
1. Fabrica remains the reference for hierarchy, project-first structure, media scale and disciplined spacing.
2. Nolan Arc owns color, typography, grain tone, glass depth and interactive components.
3. Yrsa returns to all high-level editorial headings; Syne remains the structural/UI typeface; DM Sans remains the reading typeface.
4. The floating dark glass header and the bottom mobile glass dock return.
5. Focus Testimonials returns to its interactive flowing-text behavior instead of a generic testimonial grid.
6. Contact returns to the compact V11 composer: intent → message → identity → optional budget/company.
7. Mobile receives explicit layout rules rather than inheriting desktop geometry.

## Non-goals
- Do not copy Fabrica source code.
- Do not turn every section into glass.
- Do not display every Framer-inspired component on every page.
- Do not add unverified projects or business results.
